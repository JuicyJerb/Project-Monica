# Project Monica — Privacy Policy **Last Updated:** October 4, 2026 This Privacy Policy explains how Project Monica handles information when you use the Project Monica Discord bot. Project Monica is a private, friends-only Discord bot operated as a personal software project. ## 1. Information Project Monica May Process Depending on the features enabled, Project Monica may process information such as: - Discord user ID - Discord username or display name - Discord server and channel information necessary for the bot to function - Messages or commands sent to Project Monica - Information provided directly during conversations with the bot - Bot configuration and preferences - Information stored as part of Project Monica's optional memory system - Technical information necessary to operate and troubleshoot the bot Project Monica does not intentionally request Discord passwords, authentication tokens, or other Discord login credentials from users. ## 2. How Information Is Used Information may be used to: - Respond to Discord commands and messages - Provide Project Monica's features - Maintain optional conversational memory - Remember user preferences when memory functionality is enabled - Troubleshoot and improve the bot - Maintain the security and reliability of the bot - Provide future AI or voice functionality when those features are enabled Project Monica will not intentionally use Discord information for unrelated advertising or marketing. ## 3. AI Processing If AI conversation features are enabled, messages and other information necessary to generate a response may be sent to an AI service provider. AI providers may process submitted information according to their applicable terms and privacy policies. Project Monica will only send information that is reasonably necessary for the requested AI functionality. ## 4. Persistent Memory Project Monica may store information in a persistent memory system. Memory may be used to provide personalized and continuous conversations. Users may request deletion of information stored by Project Monica's memory system. The specific memory system and storage practices may change as Project Monica develops. This Privacy Policy will be updated when those changes materially affect user data. ## 5. Voice Features Voice functionality is planned for a future version of Project Monica. If voice features are introduced, this Privacy Policy will be updated before or when those features become available to explain: - What voice data is processed - Whether audio is temporarily or permanently stored - Which third-party services process the audio - How long information is retained - How users can request deletion ## 6. Information Sharing Project Monica does not sell personal information. Information may be shared with third-party service providers when necessary to provide functionality requested by the user. For example, AI processing may require sending relevant conversation content to an AI service provider. Project Monica will not intentionally share information with third parties for unrelated advertising purposes. ## 7. Data Retention Information may be retained for as long as reasonably necessary to provide the functionality for which it was collected. Information that is no longer necessary may be deleted. Because Project Monica is an evolving personal project, retention periods may change as the system develops. Material changes to data retention practices will be reflected in an updated Privacy Policy. ## 8. Data Deletion Requests Users may request deletion of information associated with their use of Project Monica. A deletion request should identify the Discord account or information involved and may be submitted through the Discord server where Project Monica is operated. Reasonable steps may be taken to verify the request before deleting information. ## 9. Security Reasonable technical and administrative measures will be used to protect information handled by Project Monica. However, no internet-connected system can be guaranteed to be completely secure. ## 10. Children's Privacy Project Monica is not intentionally designed to collect personal information from children under the minimum age permitted by applicable law. Project Monica users must also comply with Discord's age requirements and policies. ## 11. Discord Project Monica operates through Discord and uses Discord's services and APIs. Discord independently processes information according to its own Privacy Policy and Terms of Service. Project Monica is an independent application and is not owned, operated, or endorsed by Discord. ## 12. Changes to This Privacy Policy This Privacy Policy may be updated when Project Monica's functionality, data practices, or third-party services change. The "Last Updated" date at the top of this page indicates when the policy was most recently revised. ## 13. Contact Questions or privacy requests regarding Project Monica may be submitted through the Discord server where Project Monica is operated. ## 14. Summary In simple terms: Project Monica may process Discord information and conversations so that the bot can function. If AI or persistent memory is enabled, relevant information may be processed or stored to provide those features. Project Monica does not sell personal information. Users may request deletion of information stored by Project Monica.
